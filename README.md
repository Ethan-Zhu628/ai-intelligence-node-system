# OpenClaw Lite on Mac: Local AI Intelligence Node

I built a lightweight **local AI intelligence node** on a Mac in about 48 hours.

This project explores a simple idea:

> AI does not always need to live in the cloud.  
> A personal computer can run its own intelligence workflow.

## What this is

This is a local-first AI intelligence system built around a **signal-triggered architecture**.

Instead of continuously calling AI models, the system monitors signals and only triggers analysis when meaningful changes appear.

The Lite version includes:

- Local dashboard
- Signal monitoring scripts
- Macro risk scoring logic
- Telegram alert integration
- Lightweight local deployment on macOS

## Why it matters

Most AI agent demos today run on cloud servers.  
This project asks a different question:

**Can a personal computer run its own AI intelligence node?**

The answer is yes.

## Core ideas

- Local-first deployment
- Signal-triggered AI activation
- Low token consumption
- Personal intelligence infrastructure
- Modular dashboard + alerts + scripts
